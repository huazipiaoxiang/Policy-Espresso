# 02 · PRD（MVP 版）

## 1. 背景与问题

金融机构的政策研究目前依赖人工浏览政府网站、媒体、律所简报，存在三个结构性缺陷：

1. **发现滞后**：政策通常先以"通知/办法/征求意见稿"形式在小范围发布，等到媒体解读时窗口已关闭。
2. **适用性误判**：政策文本中的"适用主体"限定（如"境内法人银行""中资商业银行"）极易被忽略，导致外资行误判"与我无关"。
3. **影响无法落地**：即使看到了政策，也难快速回答"影响我哪条业务线、哪些客户、多少钱、多久内要动作"。

**真实教训（用例 1）**：广东省一项贷款贴息政策初期仅覆盖内资银行，汇丰未及时识别，部分客户因成本差异转向内资行，涉及规模达数十亿元的贷款险些流失；后经推动政策将外资行纳入才扭转。核心不是"没看到新闻"，而是"没识别适用主体差异 + 没算客户暴露 + 没及时通知客户经理"。

## 2. 产品定位

> 不是"政策新闻聚合器"，而是**政策 → 业务影响 → 行动建议**的决策支持系统，且每一个结论都能回溯到原文。

三条产品原则：

| 原则 | 含义 | 反例 |
|---|---|---|
| 证据优先 | 无原文引用不出结论 | "预计影响利息收入 2 亿"（无依据） |
| 差异优先 | 优先识别"外资行被区别对待"的条款 | 只做主题分类不做主体判定 |
| 人审优先 | AI 出草稿，人出判断 | 自动推送到客户经理 |

## 3. 用户与场景

| 角色 | 每天做什么 | 系统提供什么 |
|---|---|---|
| 政策研究员（主要用户） | 扫渠道、判重要性、写简报 | 雷达流 + 抽取结果 + 影响评分 + 一键成稿 |
| 合规/公共事务 | 评估监管口径、对外沟通 | 适用范围判定 + 证据链 + 外发口径改写 |
| 业务线主管（CMB/GBM/WPB） | 判断要不要动客户 | 影响卡片 + 受影响客群 + 建议动作 + 时间窗 |
| 客户经理（只读） | 知道该联系谁 | 定向推送 + 客户清单（脱敏） |
| 系统管理员 | 保系统活着 | 数据源健康、任务失败、模型成本 |

## 4. MVP 范围

### 4.1 做（In Scope）

1. **监测**：≥12 个数据源，覆盖中国香港官方（HKMA、政府新闻公报、FSTB、LegCo、宪报）、中央部委（商务部 CEPA、人民银行、发改委、金融监管总局）、大湾区（广东省、深圳、南沙/前海/横琴/河套）、财经媒体。
2. **抽取**：12 个结构化字段（见 04 文档），全部带原文 span。
3. **适用范围判定**：判定目标主体"被覆盖 / 被排除 / 未提及 / 不适用"，并单独标记"外资行差异条款"。
4. **影响分析**：8 维评分、传导链、受影响业务线与客群、金额区间（带假设）、建议动作与时间窗、置信度。
5. **审核**：审核队列、双签、驳回理由、退回补充、批量操作、审计留痕。
6. **分发**：站内通知（必做）+ 邮件/IM webhook（可选配置）。
7. **案例库**：≥10 条历史案例（含用例 1），可检索、可在分析时被 RAG 引用。
8. **政策 2.0 工作台**：CEPA 主题语料 → 条款演化 → 建议书生成 → 边界校验。
9. **数据源健康**：成功率、延迟、连续失败告警。

### 4.2 不做（Out of Scope，至少 MVP 不做）

- 不做实时（秒级）监测，30 分钟粒度足够。
- 不做自动发布到外部（无人工签发不得外发）。
- 不做客户级真实数据接入（用合成数据）。
- 不做多租户、不做移动端 App（响应式网页即可）。
- 不做政策"预测未来会不会出台"（只做"已出台/征求意见"的影响分析 + 政策 2.0 的建议生成，二者不同）。
- 不做社交媒体验证与舆情打分。

## 5. 关键功能定义

### 5.1 政策卡片（Policy Card）
最小信息单元，包含：标题、发文机关、发布日期、生效日期、地域、政策类型（法律/规例/指引/通告/征求意见稿/预算案措施/新闻稿）、主题标签（跨境支付、人民币国际化、贷款与贴息、跨境理财通、保险、税务、数据跨境、资本市场、绿色金融…）、影响评分、状态。

### 5.2 影响评分卡（8 维，0–5 分）

| 维度 | 说明 | 权重 |
|---|---|---|
| 相关性 relevance | 是否直接涉及汇丰在港/大湾区业务 | 25% |
| 暴露规模 exposure | 涉及业务量级（贷款余额/AUM/交易笔数） | 20% |
| 紧迫性 urgency | 距生效日/申报截止的时间窗 | 15% |
| 方向性 direction | 利好 / 利空 / 双刃 / 中性（不参与加权，单独呈现） | — |
| 确定性 certainty | 已生效 / 已颁布未生效 / 征求意见 / 吹风 | 10% |
| 可行动性 actionability | 30 天内能否采取具体动作 | 10% |
| 差异化 differential | 是否对外资行更不利（**核心维度**） | 15% |
| 合规敏感度 compliance | 是否触及监管红线、需报备 | 5% |

综合分 → 优先级：
- **P0** ≥ 80：当日必须有人处理
- **P1** 60–79：24 小时内
- **P2** 40–59：本周内
- **P3** < 40：归档观察

> 评分必须给出"为什么是这个分"的逐维理由 + 证据；仅给总分视为不合格输出。

### 5.3 外资行差异条款检测器（差异化能力）

规则 + LLM 双通道：
1. **规则通道**：正则/词典匹配适用主体表述——"中资商业银行""境内法人银行""国有大型银行""股份制银行""城市商业银行""农村金融机构""外资银行""境外金融机构""合资格机构"。
2. **LLM 通道**：判断"目标主体是否属于适用范围内"，输出 `covered | excluded | not_mentioned | na` + 理由 + 证据 span。
3. **冲突处理**：两通道不一致时，标 `needs_review` 并在审核台高亮，不得自动降级。
4. **实体清单**：`seed/target_entities.json` 只维护两个目标主体——`hsbc_hk`（香港上海汇丰银行有限公司，香港注册认可机构）与 `hsbc_cn`（汇丰银行（中国）有限公司，内地注册外商独资法人银行），含法律性质与适用监管口径，作为判定依据。

   **边界（明确不做）**：恒生银行及其他集团附属公司**不纳入分析范围**。若政策原文点名集团其他成员，只在结果中打 `group_affiliate_mention` 标记并在审核台提示一句，不影响对上述两个实体的 `covered / excluded` 判定，也不单独生成预警。理由：附属公司有独立的政策应对与合规口径，混入同一评分卡会污染"对汇丰的影响"这一核心结论。

### 5.4 审核工作流

```
draft → ai_checked → pending_review → in_review → approved → published
                                      ↘ rejected
                                      ↘ needs_info → pending_review
```
- 双签规则：P0/P1 需"分析师 + 合规或业务主管"两级；P2/P3 单签即可。
- 强制字段未填不得提交：证据 ≥1 条、置信度、影响范围、建议动作、外发口径。
- 驳回必须选原因码（证据不足/影响误判/适用性误判/表述不当/重复），并可加备注。
- 所有修改保留字段级 diff。

### 5.5 政策 2.0（生成式推演）

输入：按主题整理的历史政策语料（例：CEPA 2003 主协议 + 历次补充协议 + 服务贸易协议修订 + 大湾区先行先试措施）。
输出：一份**建议书**，每条建议固定 5 段结构：
1. 现行依据（引用具体文件与条款）
2. 不冲突论证（为何在现行法律与监管边界内）
3. 拟条文（可执行的表述，含适用主体、条件、程序）
4. 影响评估（对港经济、对汇丰业务）
5. 风险与缓释（含被否决的可能原因）

**红线**：不得生成违反宪法、基本法、国安法及现行监管规定的内容；所有输出标注"AI 生成，未经审核不得对外"；必须经政策专家 + 合规双审。

## 6. 成功指标（MVP 验收用）

| 指标 | 目标 | 测法 |
|---|---|---|
| 抓取成功率 | ≥95% | 单次运行成功源/总源 |
| 入库及时性 | 官方发布后 ≤60 分钟入库 | 发布时间 vs 抓取时间 |
| 字段抽取准确率 | ≥85% | 人工抽检 50 条 |
| 适用范围判定准确率 | ≥90%（重点样本集） | 30 条标注样本 |
| 无证据结论率 | **0** | 自动校验，必须为 0 |
| 误报率（P0/P1 中实际不相关） | ≤15% | 审核驳回统计 |
| 审核平均耗时 | P1 ≤30 分钟 | 系统计时 |
| 用例 1 复现 | 通过 | 见 09 文档剧本 |

## 7. 依赖与假设

- 官方站点 RSS 可用（已确认 HKMA、news.gov.hk 提供 RSS）。
- 客户暴露数据 MVP 用合成集；上线前需接内部数据仓（另立项）。
- 模型可选本地（Ollama）或云端（百炼），无网环境需能降级为 Mock/规则模式。
- 法务确认：仅存储摘要与引用片段 + 原文链接，不整篇转载付费媒体内容。
